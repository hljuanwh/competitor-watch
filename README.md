# 竞品观测平台 · 可点击原型

一个 AI 竞品观测平台的前端原型：竞品一有新动态就自动写成摘要和解读，每月出月报并推送到飞书群，年底出年度报告。做成可配置的平台，其他团队换成自己的竞品和订阅人就能用。

在线体验：https://sherry2859.github.io/competitor-watch/

## 观测空间

左上角「观测空间」可以切换三个空间，8 个页面都跟着换数据。网址后加 `?s=b2b` 或 `?s=news` 可以直接打开对应空间。

| 空间 | 参数 | 追踪对象 | 收录 |
|---|---|---|---|
| CCM 云文档 | 默认 | Google Workspace、Microsoft 365、Notion、ChatGPT、Claude、腾讯文档、WPS、钉钉文档 | 60 条 |
| B 端 AI 办公 | `?s=b2b` | 飞书、钉钉、企业微信、Microsoft 365 Copilot、Google Workspace、Slack、Notion、ChatGPT 企业版、Claude 企业版、Grok Bot、Meta Muse | 53 条 |
| AI 热门资讯 | `?s=news` | OpenAI、Anthropic、Google、Meta、xAI、DeepSeek、字节、阿里、腾讯、月之暗面等，按模型发布、新产品、新功能、新趋势、资本动向、监管与事件分类 | 38 条 |

## 页面

| 页面 | 文件 | 能做什么 |
|---|---|---|
| 总览 | `index.html` | 最近完整月（10 月）的结论、更新信号时间轴、主题分布 |
| 动态 | `feed.html` | 搜索，按月份、来源、竞品、主题筛选，保存筛选，导出 |
| 动态解读 | `detail.html` | 单条动态的摘要、原文、AI 解读、同主题动态，标记有误 |
| 月报 | `monthly.html` | 7–11 月切换，各主题小结，飞书月报卡片预览 |
| 年报 | `annual.html` | 每月动态数、竞品 × 月份热力表、年度主题 |
| 订阅 | `subscribe.html` | 新建、编辑、暂停订阅，按订阅规则预览消息 |
| 任务 | `tasks.html` | 抓取 → 去重 → 撰写 → 推送流水线，运行记录，数据源状态 |
| 配置 | `config.html` | 竞品与来源、主题分类、推送渠道、AI 写作规则 |

## 数据口径

- 收录范围：2026-07-01 至 2026-11-15，全部是公开信息，每条附原文链接。数据在 `data.js`（CCM 云文档）、`data-b2b.js`、`data-news.js`。
- 「官方」是厂商自己的更新日志或博客；「媒体」是新闻报道或转载，官方原文读不到时使用。
- 没有检索到可核实发布的月份如实留空，例如 CCM 空间的 WPS 8–11 月、B 端空间的钉钉 9 月以外和 Slack 9 月以外。
- OpenAI 官方页面检索时无法读取，相关条目用媒体报道或发布说明索引，标「媒体」。
- 订阅群、推送时间、任务运行记录、数据源状态属于平台内部数据，公开信息里拿不到，页面上标「示意」。
- 各月月报的标题、导语和主题小结由 AI 根据当月动态写成，只使用收录条目里出现过的事实。

## 本地运行

纯静态页面，没有构建步骤和依赖。直接用浏览器打开 `index.html`，或者在这个文件夹里起一个静态服务：

```bash
python3 -m http.server 8000
```

然后访问 http://localhost:8000 。

## 文件

- `shared.css`：全部样式。第 1 部分与原始首页设计稿逐值一致，第 2 部分是子页面和交互组件
- `shell.js`：侧栏、图标、弹窗、提示条等各页共用的部分
- `data.js`、`data-b2b.js`、`data-news.js`：三个空间收录的动态和各月月报文字
- `spaces.js`：每个空间的竞品、主题分类、数据源、示意订阅和预设筛选，以及当前空间的选择

新建的订阅、保存的筛选按空间分开存在当前浏览器里，没有后端。
